# Engineering Research Prompt

## Topic

[INSERT TOPIC]

## Objective

Research this topic to support a technically accurate engineering article.

Do not write the final article yet.

## Research Goals

Identify:

1. Core definition
2. Architecture
3. Main components
4. Important terminology
5. Typical implementation patterns
6. Industry-standard approaches
7. Common failure modes
8. Testing and evaluation methods
9. Important metrics
10. Trade-offs
11. Security considerations
12. Performance considerations
13. Cloud / distributed-system implications
14. Relevant standards or authoritative references
15. Recent changes or developments if the topic is time-sensitive

## Source Preference

Prioritise:
- official documentation
- standards bodies
- recognised engineering organisations
- academic papers
- vendor engineering documentation
- reputable technical publications

Avoid relying heavily on generic blogs when stronger sources exist.

## Output Format

Return research notes under these headings:

### Core Concept

### Architecture

### Terminology

### Testing / Evaluation

### Failure Modes

### Metrics

### Trade-offs

### Security

### Practical Examples

### Authoritative References

### Open Questions

Keep the notes concise.

Do not turn this into a polished article yet.
