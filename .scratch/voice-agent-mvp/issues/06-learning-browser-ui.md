# 06: Add the learning browser interface

**What to build:** A polished browser UI lets the learner start a learning
session, ask questions, and inspect the active or completed transcript.

**Blocked by:** 01: Create the voice-agent project foundation.

**Status:** implemented

- [x] The UI displays **Start learning session** and **Show conversation**.
- [x] Start creates a visible connecting, active, and ended state.
- [x] A completed or active session displays learner and agent turns.
- [x] Every evidence-based answer displays source title and excerpt.
- [x] The UI announces terminal and error states accessibly.
- [x] Layout is responsive and usable by keyboard and screen reader.
- [x] Playwright tests cover session start, typed question, fallback, and
      transcript display.
