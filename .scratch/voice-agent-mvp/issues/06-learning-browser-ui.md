# 06: Add the learning browser interface

**What to build:** A polished browser UI lets the learner start a learning
session, ask questions, and inspect the active or completed transcript.

**Blocked by:** 01: Create the voice-agent project foundation.

**Status:** ready-for-agent

- [ ] The UI displays **Start learning session** and **Show conversation**.
- [ ] Start creates a visible connecting, active, and ended state.
- [ ] A completed or active session displays caller/learner and agent turns.
- [ ] Every evidence-based answer displays source title and excerpt.
- [ ] The UI announces terminal and error states accessibly.
- [ ] Layout is responsive and usable by keyboard and screen reader.
- [ ] Playwright tests cover session start, typed question, fallback, and
      transcript display.
